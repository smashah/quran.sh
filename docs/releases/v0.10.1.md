# quran.sh v0.10.1 — everything on the latest releases

This patch moves every dependency to its newest release, with no change to how the readers behave.

## What changed

- OpenTUI `@opentui/core`, `@opentui/react` and `@opentui/three` 0.8.0, effect 4.1.0, react 19.3.1, three 0.186.1 with @types/three 0.186.0, @types/react 19.3.0, @types/bun 1.4.4, and onnxruntime-node 1.31.1.
- Search results and verse sync use OpenTUI 0.8's `scrollChildIntoView`, which keeps the selected result and the current verse in view after layout changes.
- The 3D reader's glyph outlines use three r186's `ShapePath.toShapes()`.
- onnxruntime-node 1.31 turns on telemetry by default, so quran.sh sets `ORT_DISABLE_TELEMETRY=1` before loading it unless you have set it yourself.

The release passes 218 tests, the TypeScript 7 typecheck, source and standalone builds, the smoke paths, and the lazy-import verifier, and the dashboard, immersive (including the WebGPU 3D reader) and stream readers were checked by hand.

See [CHANGELOG.md](https://github.com/smashah/quran.sh/blob/v0.10.1/CHANGELOG.md) for details.
