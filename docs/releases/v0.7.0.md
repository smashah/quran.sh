# quran.sh v0.7.0 — attentive reading, optional depth

This release keeps the offline Quran reader as the default and adds an opt-in immersive path for focused reading, learning, recitation, memorisation, native terminal scrollback, verified QUL study packs, local Tilawa following, and restrained OpenTUI Three illumination.

![quran.sh v0.7.0 walkthrough](https://github.com/smashah/quran.sh/releases/download/v0.7.0/quran-next-generation.gif)

## Highlights

- `quran immersive` provides Focus, Learn, Recite, and Memorise modes, responsive layouts, a 180 ms focus transition, reduced motion, and local capability failures that never take down Quran text.
- `quran stream` commits completed ayat as selectable, copy-safe terminal scrollback while its footer remains live.
- `quran resources` imports user-obtained QUL JSON/SQLite data after validating all canonical Quran keys, source hash, compatibility, license, and attribution. It builds a namespaced indexed SQLite copy and never scrapes QUL or assumes dataset redistribution rights.
- Attributed recitation rows can drive OpenTUI Audio and visible word highlighting only when ordered timing segments validate; otherwise playback remains safely ayah-level.
- `quran models install official --yes` installs the separate ~104 MiB Tilawa v0.2.0 assets with a disk preflight, streaming hashes, atomic promotion, verification, and removal. Follow mode asks for microphone consent, keeps PCM local, never retains audio, and navigates only on committed verse matches.
- The released `@opentui/three` 0.4.5 experiment probes WebGPU after explicit consent, requests no idle frames, and disposes its device/geometry/materials. Mushaf rails stay hidden unless a licensed layout pack passes full 604-page/6,236-ayah coverage.
- The Braille image pane is a separate deferred chunk; fetching, decode, cooperative rasterisation, source pixels, and grids are bounded and unload when the pane closes.

## Size and safety gates

The startup entry is 2,444 bytes and `quran --help` measures 17 ms / 23.5 MB peak RSS on the recorded macOS arm64 baseline. The release passes 175 tests, strict TypeScript, source and standalone builds, macOS/Linux/Windows smoke paths, the lazy-import verifier, a clean `bun audit`, and reviewed package/binary/lifecycle budgets.

Optional packs, network audio, image requests, microphone capture, ONNX, and WebGPU activate only after a user command. `quran safe` ignores every optional subsystem, while `quran doctor` reports capabilities, disk use, licenses, cache size, and privacy without telemetry.
